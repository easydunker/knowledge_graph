# Zotero Plugin Placeholder

Zotero is optional and not part of v1 core.

Future plugin capabilities:

- Read Better BibTeX export from `plugins/zotero/library.bib`.
- Match Zotero items to existing paper notes by DOI, title, PDF hash, or author-year-title.
- Add Zotero citekeys and tags to paper note frontmatter.
- Create paper notes from Zotero entries only when explicitly requested.

Restrictions:

- No Zotero write-back in v1.
- No direct writes to `zotero.sqlite`.
- No silent replacement of researcher-reviewed Markdown.
